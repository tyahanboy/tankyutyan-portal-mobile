# たんきゅーちゃん Portal Mobile

Android・iOS向けのFlutterアプリプロジェクト。

## 接続先
- Webポータル: https://tankyutyan-portal.onrender.com/
- API: https://tankyutyan-api.onrender.com/

## 方針
- Android・iOS両対応を目指す。
- 既存のWebポータルとAPIは変更しない。
- 認証情報や秘密鍵をアプリに埋め込まない。
- ログイン維持、通信エラー、再読み込み、外部リンクを確認する。
